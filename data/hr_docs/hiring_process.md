# Процесс найма в ML-команду

## Общая схема

Процесс найма состоит из нескольких этапов:

1. Первичный HR-скрининг.
2. Техническое интервью.
3. Финальное интервью с руководителем или командой.
4. Обсуждение оффера.
5. Обратная связь кандидату.

На первичном HR-скрининге кандидат отвечает на короткие вопросы об опыте, целевой роли, технических навыках, образовании, городе, формате работы и зарплатных ожиданиях.

## Первичный HR-скрининг

Цель первичного скрининга - понять, к какой роли кандидат ближе всего:

- Project Manager;
- Data Analyst;
- Data Engineer;
- Data Scientist;
- MLOps Engineer;
- Not Suitable, если опыта и навыков недостаточно для текущих ролей.

HR-бот не принимает финальное решение о найме. Он помогает собрать первичную информацию и определить наиболее вероятное направление для следующего этапа.

## Техническое интервью

Техническое интервью зависит от роли кандидата.

Для Data Analyst проверяются SQL, аналитическое мышление, продуктовые метрики, визуализация, дашборды и умение формулировать выводы.

Для Data Engineer проверяются пайплайны данных, ETL/ELT, SQL, Python, Airflow, Spark, хранилища данных, качество данных и опыт работы с production data systems.

Для Data Scientist проверяются машинное обучение, Python, pandas, sklearn, feature engineering, метрики качества, статистика, эксперименты и опыт обучения моделей.

Для MLOps Engineer проверяются Docker, Kubernetes, CI/CD, MLflow, мониторинг моделей, деплой, production ML и понимание data drift/model drift.

Для Project Manager проверяются управление задачами, сроками, командой, коммуникация с заказчиками, планирование, roadmap, риски и координация между участниками команды.

## Финальное интервью

Финальное интервью обычно посвящено ожиданиям кандидата, мотивации, культурному соответствию, рабочему формату и деталям команды. На этом этапе могут обсуждаться условия оффера и возможная дата выхода.

## Сроки обратной связи

Обычно обратная связь после первичного скрининга или интервью занимает от 2 до 5 рабочих дней. Если процесс требует дополнительного согласования, срок может быть дольше.
