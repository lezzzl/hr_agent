# Роли в ML-команде

## Project Manager

Project Manager отвечает за планирование, координацию и delivery проектов. Для этой роли важны:

- управление задачами и сроками;
- коммуникация с заказчиками и командой;
- планирование roadmap;
- управление рисками;
- фасилитация встреч;
- работа с Jira, Confluence или похожими инструментами;
- понимание жизненного цикла IT- или ML-проектов.

Кандидат ближе к Project Manager, если он больше говорит об управлении процессами, командой, сроками, ожиданиями стейкхолдеров и поставкой результата.

## Data Analyst

Data Analyst помогает бизнесу принимать решения на основе данных. Для этой роли важны:

- SQL;
- Excel или Google Sheets;
- Python для анализа данных;
- BI-инструменты: Power BI, Tableau, Superset или аналоги;
- построение дашбордов;
- продуктовые и бизнес-метрики;
- проверка гипотез;
- A/B-тесты;
- визуализация и презентация выводов.

Кандидат ближе к Data Analyst, если он описывает анализ метрик, отчётность, дашборды, SQL-запросы, продуктовые исследования и работу с бизнес-заказчиками.

## Data Engineer

Data Engineer строит инфраструктуру данных и пайплайны. Для этой роли важны:

- SQL;
- Python;
- ETL/ELT;
- Airflow;
- Spark;
- Kafka;
- DWH;
- PostgreSQL, ClickHouse, Greenplum или другие базы данных;
- качество данных;
- batch и streaming pipelines;
- оптимизация обработки данных.

Кандидат ближе к Data Engineer, если он говорит о хранилищах данных, витринах, пайплайнах, интеграциях, обработке больших объёмов данных и стабильности data platform.

## Data Scientist

Data Scientist разрабатывает и оценивает ML-модели. Для этой роли важны:

- Python;
- pandas, numpy;
- sklearn;
- CatBoost, XGBoost, LightGBM;
- feature engineering;
- метрики качества моделей;
- статистика;
- машинное обучение;
- эксперименты;
- интерпретация моделей;
- работа с датасетами и признаками.

Кандидат ближе к Data Scientist, если он говорит об обучении моделей, ML-задачах, метриках, признаках, экспериментах и применении моделей для бизнес-задач.

## MLOps Engineer

MLOps Engineer отвечает за production-контур ML-систем. Для этой роли важны:

- Docker;
- Kubernetes;
- CI/CD;
- MLflow;
- мониторинг моделей;
- деплой моделей;
- model serving;
- feature store;
- data drift и model drift;
- observability;
- автоматизация ML-пайплайнов.

Кандидат ближе к MLOps Engineer, если он говорит о деплое моделей, инфраструктуре, мониторинге, production ML, CI/CD и поддержке моделей после релиза.

## Not Suitable

Роль Not Suitable выбирается, если кандидат не показывает достаточных признаков ни одной целевой роли, отвечает слишком общо или описывает опыт, который не связан с IT, аналитикой, данными, ML или управлением такими проектами.
